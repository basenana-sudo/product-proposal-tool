# コラボ候補集め｜設計まとめ

> 目的は「新素材を探す」ことではない。**自社商品と組める素材・商品・部材**を集め、提案ツールのインプットにする。  
> 出典: 2026-07-03 設計整理＋2026-07-16 方針修正（新素材探索 → コラボ候補探索）。

### 探索の軸

| 軸 | 何を見るか | 例（自社ライン想定） |
|---|---|---|
| **隣接部材** | 現場で隣に付くもの | 巾木、見切り、目地材、下地、ファスナー、金物 |
| **同現場の他カテゴリ** | 同じ改修・新築で一緒に選ばれるもの | 外壁、天井、間仕切り、建具、床材 |
| **機能の掛け合わせ** | 自社の強みを伸ばす相手 | 防音×吸音、ルーバー×遮熱／採光、塗り床×耐薬品／帯電防止 |
| **売り先の課題** | 施設側の困りごとから逆引き | 工場＝衛生・耐荷重、医療＝抗菌・メンテ、商業＝意匠・更新周期 |

判定の基準は「新しいか」ではなく、

1. 自社のどの商品の**隣**に付くか
2. セットで売ると、顧客のどんな手間が減るか
3. 自社だけでは足りない機能を、相手が補うか

### 自社商品ライン（探索の起点）

提案ツール側の想定カテゴリ（例）:

- 合成樹脂系塗り床 / 無機系塗り床（硬質床）
- 長尺シート・置敷タイル / セラミックタイル
- 内外装ルーバー / 庇・ライトシェルフ / 笠木
- 防音パネル・防音ルーバー / 腰壁保護シート

情報収集は「素材全般」ではなく、**上記の隣・セット・機能補完**に寄せる。

---

### 全体の流れ

```
情報源を週1で見る（メーカー周辺製品・施工事例・業界メディアなど）
　↓
自分が取捨選択（人間フィルター：「組めるか？」で判断）
　↓
AIにコラボ候補として整理を依頼
　↓
提案ツールの左ペインに貼り付け
　↓
アイデア生成 → 提案フォーム記入
```

Googleアラートは補助。主戦場ではない（ノイズが多く、コラボ観点とズレやすい）。

---

### 情報源（優先順）

1. **メーカーの周辺製品・関連商品ページ／カタログ**  
   自社品の隣に並ぶ部材・セット提案を見る
2. **施工事例・改修事例**  
   「何と何が同時に入っているか」がいちばん参考になる
3. **仕様書・標準納まり図**  
   セット指定されやすい部材が分かる
4. **業界メディア・展示会（組み合わせブース優先）**  
   新製品単体より、同梱・パッケージ提案を拾う
5. **定型検索（週1・過去1週間）** ※アラートの代わり  
   例: `塗り床 巾木` / `ルーバー 金物` / `防音パネル 換気` / `工場 床改修 セット`

---

### 登録・検索キーワードの考え方

「新素材」「新技術」より、**自社商品名＋隣接語／施設課題**で探す。

**隣接・セット系**
- `塗り床 巾木` / `塗り床 目地` / `塗り床 下地`
- `ルーバー 金物` / `ルーバー ブラケット` / `ルーバー 遮熱`
- `防音パネル 吸音` / `防音ルーバー 換気`
- `腰壁保護 コーナーガード`

**施設課題系**
- `工場 床改修` / `食品工場 床 衛生`
- `医療 防音` / `商業施設 外装 メンテフリー`
- `大規模修繕 外装` / `ZEB 外装 ルーバー`

**メーカー・展示会（補助）**
- 主要メーカーの「関連商品」「納まり」「施工事例」
- `JAPAN BUILD` などの展示会レポート（組み合わせ提案を優先）

最初は **5〜10語**に絞る。多すぎると読む気が失せる。

---

### AIへの整理依頼プロンプト（テンプレート）

集めた記事・URLメモを貼り付けて使う:

```
以下の建材・商品情報を読んで、自社商品とのコラボ／組み合わせ候補として整理してください。
自社商品ライン：合成樹脂系塗り床／無機系塗り床／内外装ルーバー／防音パネル・防音ルーバー／腰壁保護シート など

【出力形式】
■ 組み合わせ候補（自社商品 × 相手素材・部材・商品）3〜5件
■ なぜ組めるか（現場・機能・売り先の理由を1行ずつ）
■ 提案しやすい施設・用途（工場／医療／商業など）
■ 要確認事項（規格・施工・競合リスクなど）

---
（ここに記事やURLメモを貼る）
```

### 注意点・補足

- 「面白い新素材」より **「一緒に提案できるか」** で残す／捨てる
- 届いた情報すべてを使う必要はない。組める感がないものは捨ててよい
- 3ヶ月使って「この検索語は使えない」と感じたら削除・変更する
- Googleアラートを残すなら、キーワードを隣接語・施設課題に差し替えて補助扱い
- 将来自動化するなら: RSS（業界メディア）＋週次まとめ。フルオート収集は、何が「組める相手」か身体で分かってから
