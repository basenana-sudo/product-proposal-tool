# 新商品提案ツール

建材向けの社内新商品提案を支援するツールです。素材×自社商品からアイデアを量産し、提案書を自動生成します。

## 構成

| フォルダ | 説明 |
|---|---|
| ルート（`app/`, `components/` など） | **Next.js版** — 開発中の本体 |
| `html-standalone/` | **HTML版** — ブラウザで単体動作する完成版 |

## 使い方（Next.js版）

```bash
npm install
npm run dev
```

http://localhost:3000 を開いてください。

## 使い方（HTML版）

`html-standalone/index.html` をブラウザで開くだけで動作します。
